# 🍔 Taxi-Burger.bd

A modern **food ordering web app** built with HTML, CSS (Tailwind), and JavaScript.  
It allows users to browse delicious food items, view details, and add them to the cart.

---
##Tech Stack

- `index.html` — Main HTML page  
- `js/index.js` — Core JavaScript logic (display foods, add to cart, modal handling, etc.)  
- `assets/` — Static files (images, CSS, icons)  
- `tailwind.config.js` — Tailwind CSS configuration  

---

## ✨ Features

- Display list of food items dynamically  
- Show food details in a modal on card click  
- Add items to the cart using the “Add This Item” button  
- Automatically increase quantity if the same item is added again  
- Update total price dynamically  
- (Optional) Save cart data to `localStorage` for persistence
